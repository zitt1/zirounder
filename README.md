# zirounder — Легкое скругление углов экрана для Android

**zirounder** — это минималистичное и невероятно легкое приложение для Android, позволяющее скруглить углы вашего дисплея для придания смартфонам и планшетам современного эстетичного вида.

### ✨ Ключевые возможности:
- 📐 **Стандартный радиус 15px**: Готовые пресеты (15px, 20px, 28px, 36px) и ручная точная настройка радиуса каждого угла.
- 🌍 **Мультиязычность (Onboarding)**: При первом запуске доступен быстрый выбор языка (Русский / English) и моментальная настройка всех необходимых разрешений.
- ⚡ **Максимальная легкость и экономия АКБ**: Оверлей выключается во время блокировки экрана и использует аппаратную векторную отрисовку Canvas без лишних фоновых процессов.
- 🎨 **Гибкий внешний вид**: Выбор формы (Круглая, Squircle / суперэллипс, Фасетный notch), регулировка цвета (AMOLED #000000) и прозрачности.
- 🔕 **Без лишних уведомлений**: Оверлей работает тихо и ненавязчиво.

# zirounder — Lightweight Screen Corner Rounder for Android

**zirounder** is a clean, minimal, and extremely lightweight Android application designed to give your smartphone or tablet screen elegant rounded corners.

### ✨ Key Features:
- 📐 **Standard 15px Corner Radius**: Quick presets (15px, 20px, 28px, 36px) with individual 4-corner customization support.
- 🌍 **Language Choice Onboarding**: Choose your preferred language (English or Russian) on first launch and grant permissions in just 2 simple steps.
- ⚡ **Ultra Lightweight & Battery Friendly**: Auto-pauses when the screen locks and draws statically via hardware Canvas with zero CPU polling loops.
- 🎨 **Customization Options**: Select shape styles (Round, Squircle / superellipse, Chamfered notch), custom colors (OLED pure black #000000), and opacity.
- 🔕 **No Distracting Notifications**: Operates quietly in the background without clutter.
